# Тихий Рынок — конструктор брендбука

Одностраничное приложение на чистом HTML/CSS/JS (ES-модули, без сборки и зависимостей).
Помогает собрать минимальный брендбук: бриф, палитра, типографика, постер и карточка
для соцсетей, печать в PDF.

## Запуск

**ES-модули не работают при открытии через `file://`**, поэтому нужен локальный сервер.
Двойной клик по `index.html` покажет подсказку вместо приложения — это ожидаемо.

Любой из вариантов:

1. Python (обычно уже установлен):
   ```bash
   python -m http.server 8080
   ```
   затем открыть http://localhost:8080

2. Node.js:
   ```bash
   npm start
   ```
   (запускает `npx serve` на порту 8080)

3. VS Code: расширение **Live Server** → «Open with Live Server».

## Структура

```
index.html        разметка: бриф, палитра, типографика, макеты, итоговый брендбук
css/common.css    все стили, включая print-режим (@page A4) и prefers-reduced-motion
js/state.js       стартовое состояние, пресеты палитр и шрифтов
js/storage.js     сохранение черновика в localStorage (ключ brandbook-draft)
js/tokens.js      экспорт дизайн-токенов в JSON
js/brief.js       поля брифа и их валидация
js/color.js       палитры, своя палитра, расчёт контраста текста
js/typography.js  выбор шрифта, размера и насыщенности
js/layouts.js     макеты, фоновая картинка, печатные копии, сводка
js/main.js        сборка модулей, единый render() и debounce-сохранение
```

## Данные

Черновик лежит в `localStorage` под ключом `brandbook-draft` и никуда не отправляется.
Настройки **не переносятся ссылкой** и не синхронизируются между браузерами.
Кнопка «Сбросить» удаляет черновик (с подтверждением). Сохранение отложено на 0,5 с,
но при закрытии вкладки последние правки дописываются принудительно.

## Экспорт

Кнопка «Скачать токены» отдаёт JSON: название и слоган, бриф, цвета палитры с HEX,
параметры типографики и композицию. Файл именуется по названию бренда, например
`тихий-рынок-tokens.json`. Импорта пока нет.

## Свои изображения

Заглушки в постере и карточке — инлайн-SVG, собранные на цветах палитры, поэтому
перекрашиваются вместе с брендом и не требуют сети. Чтобы поставить свою картинку,
замените `<svg class="poster-visual">` (или `<svg class="card-skin">`) на
`<img class="poster-visual" src="assets/skin.png" alt="Визуал скина">` —
классы и стили останутся рабочими.

## Печать

Кнопка «Печать / PDF» (или Ctrl+P). Документ готовится под A4 с полями 14 мм:
сводка брифа, таблица цветов с HEX-кодами и два макета. В диалоге печати
**включите «Фон и изображения» / «Background graphics»** — иначе постеры и
карточки напечатаются без заливки.

## Известные ограничения

- Шрифты грузятся с Google Fonts по требованию: Inter — сразу, остальные — при
  выборе семейства; без сети используется системный `sans-serif`.
- Нет импорта/экспорта проекта и экспорта дизайн-токенов.
- Контраст проверяется по WCAG для пяти пар «текст / фон»; нечитаемую палитру
  панель помечает «не проходит», но выбор не блокирует.
- Браузеры: актуальные Chrome, Edge, Firefox, Safari (нужны `aspect-ratio`,
  `clamp()`, CSS-переменные).
